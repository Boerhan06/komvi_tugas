Flowchart 1: Pipeline Kalibrasi Kamera Chessboard

flowchart TD Start(["Mulai Kalibrasi Kamera"]) --> InputData["Siapkan 15-25 Foto Chessboard (cal_xx.jpg)
Definisikan PATTERN_SIZE (9,6) dan SQUARE_SIZE_MM"] InputData --> LoopFoto["Iterasi Setiap Foto Chessboard"] LoopFoto --> GrayConv["Konversi Foto ke Grayscale"] GrayConv --> DetectCorner["Deteksi Sudut Dalam:
cv2.findChessboardCorners()"] DetectCorner --> CheckDetect{"Sudut Terdeteksi Lengkap?
(9 x 6 = 54 titik)"} CheckDetect -- Tidak --> LogFail["Tandai Foto Gagal / Abaikan Foto"] CheckDetect -- Ya --> SubPix["Perhalus Koordinat:
cv2.cornerSubPix()"] SubPix --> AppendPoints["Simpan 3D Object Points dan 2D Image Points"] LogFail --> CheckNext{"Masih Ada Foto Lain?"} AppendPoints --> CheckNext CheckNext -- Ya --> LoopFoto CheckNext -- Tidak --> CheckValidCount{"Jumlah Foto Valid >= 10?"} CheckValidCount -- Tidak --> ErrorCalib["PERINGATAN: Data Kurang Tajam / Kurang Sudut.
Ulangi Pengambilan Foto Kalibrasi!"] --> EndFail(["Selesai (Gagal)"]) CheckValidCount -- Ya --> RunCalib["Jalankan cv2.calibrateCamera()"] RunCalib --> ExtractParam["Ekstraksi Parameter Kamera:
fx, fy, cx, cy, Koefisien Distorsi, RMS Error"] ExtractParam --> SaveParam["Simpan Parameter Kalibrasi ke File / Memori"] SaveParam --> EndSuccess(["Selesai (Kalibrasi Berhasil)"])

Flowchart 2: Pipeline Estimasi Depth Stereo Vision

flowchart TD Start(["Mulai Stereo Depth Estimation"]) --> ReadImages["Baca Foto Kiri (left.jpg) dan Kanan (right.jpg)
Input Parameter: fx, cx, cy, Baseline B, Z_true"] ReadImages --> Undistort["Koreksi Distorsi Lensa:
cv2.undistort() pada Citra L dan R"] Undistort --> FeatureMatch["Deteksi dan Pencocokan Fitur (ORB / SIFT)
Hitung Selisih Garis Vertikal (dy)"] FeatureMatch --> CheckAlignment{"Median |dy| <= Batas Toleransi?
(Epipolar Alignment Valid?)"} CheckAlignment -- Tidak --> AutoCorrect["Coba Koreksi Geometris / Homografi Tipis"] AutoCorrect --> Recheck{"Alignment Berhasil Membaik?"} Recheck -- Tidak --> ErrorAlign["GAGAL ALIGNMENT:
Foto Terlalu Miring / Rotasi Terlalu Besar.
Ambil Ulang Foto Stereo!"] --> EndFail(["Selesai (Gagal)"]) CheckAlignment -- Ya --> DisparityCompute["Hitung Disparity Map:
cv2.StereoSGBM_create()"] Recheck -- Ya --> DisparityCompute DisparityCompute --> CheckDisp{"Disparity Positif dan Valid > 70%?"} CheckDisp -- Tidak --> SwapCheck{"Apakah Foto Kiri/Kanan Terbalik?"} SwapCheck -- Ya --> SwapImages["Tukar Citra L dan R"] --> DisparityCompute SwapCheck -- Tidak --> ErrorDisp["GAGAL: Area Terlalu Polos / Baseline Rusak"] --> EndFail CheckDisp -- Ya --> ComputeDepth["Hitung Depth Map Pixel-wise:
Z = (fx * B) / d"] ComputeDepth --> SelectROI["Tentukan Bounding Box / Titik ROI Objek Target"] SelectROI --> CalcMedianDepth["Ambil Median Disparity dan Median Depth pada ROI:
Z_est"] CalcMedianDepth --> CalcError["Hitung Galat Terhadap Meteran:
Error (%) = |Z_est - Z_true| / Z_true * 100"] CalcError --> SaveCSV["Tampilkan Visualisasi dan Simpan Log ke CSV"] SaveCSV --> EndSuccess(["Selesai (Sukses)"])
